# License / Limitations of Usage
This work uses two open-source copyright licenses with slightly different scopes. The plotting scripts interacting with csv files are covered under the MIT license, meaning they can be used by anyone for any purpose. It's just python code. The data csvs themselves are under the GNU GPLv3 license, which requires anyone making a modification to publish it publicly under the same license. This is intended to deter any non-research, for-profit entity from using the data csvs, and at least require them to do their own legwork in generating the data, and share it. For researchers, you may freely use the data csvs, but if you change or create your own data csv and use it within this framework, and the work eventually makes it to publication, please fork a copy of this repository and upload a copy of your dataset to your copy of the repository.
